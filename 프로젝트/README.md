# 🚒 소방 현장 1차 통제선 안전관리 시스템 (FirePass)

스마트폰 모바일 앱 설치 없이 웹 브라우저(PWA)에서 구동되며, **Supabase 무료 티어(PostgreSQL + Realtime)**와 **로컬 오프라인 저장소(IndexedDB)**를 연동한 1차 통제선 안전통제 시스템입니다.

---

## 📂 파일 구성 안내

- **`index.html`**: 현장 통제요원용 모바일 스캐너 (카메라 QR 고속 인식, 오프라인 로컬 저장, 진입/철수 토글, 야간 플래시, 화면 꺼짐 방지)
- **`dashboard.html`**: 현장지휘관용 실시간 관제 대시보드 (진입 중 대원 체류시간 카운트다운 타이머, 35분 초과 시 적색 점멸 경보, 출입 로그 CSV 다운로드)
- **`admin.html`**: 관리자용 대원 등록 및 헬멧 부착용 고유 QR코드 라벨 인쇄 센터
- **`supabase_schema.sql`**: Supabase 데이터베이스 생성 및 실시간 통신 활성화 SQL 스크립트
- **`config.js`**: Supabase 연동 설정 및 브라우저 키 입력 유틸리티
- **`manifest.json` & `sw.js`**: PWA (스마트폰 '홈 화면에 추가' 시 앱처럼 풀스크린 실행) 및 오프라인 캐싱 지원

---

## 🚀 3단계 빠른 시작 가이드 (전체 무료)

### 1단계: Supabase 데이터베이스 세팅 (1분)
1. **[Supabase](https://supabase.com/)** 로그인 후 **[New Project]**를 생성합니다.
2. 좌측 메뉴에서 **[SQL Editor]**를 클릭합니다.
3. 프로젝트 내 **`supabase_schema.sql`** 파일의 전체 내용을 복사하여 붙여넣고, 우측 하단의 **[RUN]** 버튼을 누릅니다.
   *(테이블 생성 및 테스트 대원 5명이 자동 등록됩니다)*
4. 좌측 메뉴 **[Project Settings (톱니바퀴)] ➔ [API]**로 이동합니다.
   - **Project URL** (예: `https://xxxx.supabase.co`)
   - **Project API keys**의 `anon public` 키  
   두 가지 값을 복사해 둡니다.

---

### 2단계: 연동 설정 (코드 수정 없이 브라우저에서 가능)
- `index.html` 또는 `dashboard.html`을 브라우저로 엽니다.
- 화면 상단의 **⚙️ 설정 버튼**을 누르고, 1단계에서 복사한 **Project URL**과 **anon public key**를 붙여넣은 뒤 **[저장 및 적용]**을 누르면 끝납니다.
  *(직접 `config.js` 파일을 열어 상단 변수에 입력해 두셔도 됩니다)*

---

### 3단계: GitHub 및 무료 웹 호스팅 배포 (선택)

스마트폰 카메라로 QR을 스캔하려면 **HTTPS 도메인**이 필요합니다. 아래 무료 호스팅 중 하나를 선택하세요.

#### 방법 A: GitHub Pages 무료 호스팅 (추천)
1. GitHub에 새 저장소(Public Repository)를 만듭니다 (예: `firepass`).
2. 이 폴더의 모든 파일들을 GitHub 저장소로 Push(업로드)합니다.
3. GitHub 저장소의 **Settings ➔ Pages** 메뉴로 이동합니다.
4. **Build and deployment** 항목의 Source를 `Deploy from a branch`로 선택하고, Branch를 `main` (또는 `master`), 폴더를 `/ (root)`로 지정한 뒤 **Save**를 누릅니다.
5. 1~2분 뒤 생성되는 무료 HTTPS 주소(예: `https://본인아이디.github.io/firepass`)로 스마트폰에서 접속합니다.

#### 방법 B: Vercel 1클릭 무료 배포
1. [Vercel.com](https://vercel.com)에 GitHub 계정으로 로그인합니다.
2. `Add New...` ➔ `Project`를 누르고 방금 만든 GitHub 저장소를 `Import`합니다.
3. 아무 설정 변경 없이 **Deploy** 버튼을 누르면 즉시 무료 HTTPS 주소가 생성됩니다.

## 📱 현장 통제요원 스마트폰 사용법 (PWA)

1. 배포된 웹사이트 주소로 스마트폰 브라우저 접속 (Android: 크롬, iOS: 사파리).
2. 브라우저 메뉴에서 **[홈 화면에 추가]** 또는 **[앱 설치]** 클릭.
3. 바탕화면에 생성된 **"소방통제선"** 아이콘을 터치하면 상단 주소창이 사라진 완전한 앱 형태로 풀스크린 실행됩니다.
4. 현장 통신이 끊겨도(지하층/비행기모드) 로컬 메모리(IndexedDB)에 0.1초 만에 안전하게 기록되며, 통신 복구 시 자동으로 클라우드로 동기화됩니다.

## 💡 주요 안전 관리 기능

1. **공기호흡기 한계시간(35분) 실시간 모니터링**:
   - `dashboard.html` 상황판에서 대원의 체류 경과 시간이 1초 단위로 카운트됩니다.
   - 30분 경과 시: 황색 주의 경보
   - 35분 초과 시: **적색 점멸(Blink) 및 진동 경보** (즉시 무전 철수 명령 권고)
2. **QR 오염/손상 대비 3단계 백업**:
   - 연기/그을음으로 QR 스캔이 불가할 경우 스캐너 하단의 **[🔍 QR 훼손 수동 검색]** 버튼을 눌러 대원 이름이나 사번으로 1초 만에 수동 진입/철수 처리 가능.
3. **완전한 엑셀(CSV) 리포트 다운로드**:
   - 지휘관 상황판 상단의 **[📥 엑셀(CSV) 다운로드]** 버튼을 클릭하면 현장 출입 일지가 표준 엑셀 호환 CSV로 저장됩니다.
